## ⚡ Quick start

### Option A — Groq or OpenRouter (fastest, no local model needed)

> Requires **Python 3.11+** only. A Groq free-tier key takes about 30 seconds to create.

**1. Get a free API key**

| Provider | Sign-up link | What you get free |
|----------|-------------|-------------------|
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) | Fast LLaMA 3.3 70B, generous rate limits |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | 200+ models, several free-tier options |

**2. Install and run**

```bash
git clone https://github.com/fayfayMN/ZeroCode-Career-Coach.git
cd ZeroCode-Career-Coach

python -m venv .venv
# Mac/Linux:
source .venv/bin/activate
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
streamlit run app.py        # opens http://localhost:8501
```

**3. In the sidebar, set up your model**

- **Provider** → pick `Groq (free tier)` or `OpenRouter`
- **API key** → paste your key (masked, session-only, never stored)
- Leave Base URL and Model at their defaults, or swap in any compatible model
- Click **"Check connection"** — you should see a green success message

That's it. Upload a resume, paste a job description, and work through the 5 steps.

### Option B — Local Ollama (private, free, full features)

> Requires **Python 3.11+** and **[Ollama](https://ollama.com/download)**.  
> If you're on Windows, run everything from a **WSL Ubuntu** shell (WSL2 forwards `:11434` and `:8501` to Windows automatically).

**1. Install Ollama and pull the models**

```bash
# Pull once — chat model (~9 GB) + embedding model (~270 MB)
ollama pull qwen3:14b-q4_K_M      # or qwen2.5:7b for a lighter ~5 GB option
ollama pull nomic-embed-text
```

**2. Install dependencies and run**

```bash
git clone https://github.com/fayfayMN/ZeroCode-Career-Coach.git
cd ZeroCode-Career-Coach

python -m venv .venv && source .venv/bin/activate   # Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -r requirements-voice.txt               # adds voice: mic recorder + Whisper + TTS

ollama serve &          # start Ollama in background (skip if already running)
streamlit run app.py    # → http://localhost:8501
```

**3. In the sidebar, select Ollama**

- **Provider** → `Ollama (local)` — no API key field appears
- **Ollama host** → `http://localhost:11434` (correct default for WSL and native installs)
- **Chat model** → match whatever you pulled (e.g. `qwen3:14b-q4_K_M`)
- **Embed model** → `nomic-embed-text` (leave blank to fall back to keyword-only scoring)
- Click **"Check connection"** — you'll see which models Ollama has available

<details>
<summary><b>Windows + WSL tip</b></summary>

Run the app from the **same WSL shell** as Ollama:

```bash
cd /mnt/c/Users/YourName/ZeroCode-Career-Coach
source .venv/bin/activate
streamlit run app.py
```

WSL2 forwards both `:11434` (Ollama) and `:8501` (Streamlit) to Windows, so you open
`http://localhost:8501` in your normal Windows browser.

Only if you run the app from **Windows** while Ollama stays in WSL do you need to change the
Ollama host in the sidebar to `http://<your-wsl-ip>:11434`
(get the IP with `wsl hostname -I`).
</details>

## 🧭 Using the app (5 steps)

| Step | What to do | What you get |
|------|-----------|--------------|
| **1 · Setup** | Upload resume (PDF/DOCX/TXT), paste job description, add optional company notes and your working-style preferences | Parsed resume, saved job details |
| **2 · Fit & Strategy** | Click **"Analyze fit"** | Score 0–100, matched/missing ATS keywords, strengths & gaps, action plan |
| **3 · Tailor Application** | Click **"Generate tailored resume + cover letter"** | Improved resume bullets (XYZ formula), cover letter, LinkedIn suggestions |
| **4 · Interview Coach** | Click **"Build interview prep plan"**, then start a mock interview (voice or text) | Question bank, technical topics, STAR-graded feedback |
| **5 · Career Dossier** | Click **"Download Career Dossier"** | One self-contained HTML file — open offline, print to PDF |

**Why the score is trustworthy:** the match score is **deterministic** (keyword coverage +
embedding similarity via rapidfuzz + Ollama embeddings), not an LLM guess — reproducible and
explainable. The LLM adds strategic judgement on top.

## 🧠 Architecture

A deliberate redesign from a sprawling 7-agent pipeline down to **3 agents + 1 deterministic orchestrator**.

```
            ┌─────────────────────────────────────────────┐
            │   Orchestrator (no LLM): CareerFile state,    │
            │   deterministic match score, dossier export   │
            └───────────────┬─────────────────────────────┘
                            │
   ┌────────────────┬───────┴────────┬───────────────────┐
   ▼                ▼                ▼                    ▼
 Recruiter        Writer            Coach            Streamlit UI
 fit + score   tailored resume   prep + voice mock   (5 guided steps)
 + strategy    + cover letter    + STAR feedback
```

| Agent | Role | Skill modules |
|-------|------|---------------|
| **Recruiter** | Screens fit like a real tech recruiter; score, strengths/gaps, action plan | `fit-analysis`, `ats-keywords` |
| **Writer** | Tailors resume bullets + writes a personable cover letter; preserves your voice | `resume-tailoring`, `cover-letter`, `voice-humanize` |
| **Coach** | Builds prep plan + runs the voice/text mock interview with STAR feedback | `interview-behavioral`, `interview-technical` |

**Skills as prompt modules:** `src/skills/*.md` hold distilled expert frameworks (ATS rules,
Google's XYZ formula, STAR, scoring rubrics). Each agent loads the relevant modules into its
system prompt — **edit a markdown file to change agent behaviour, no code change needed.**

## 🎤 Voice (local only)

Voice answers are transcribed **on your machine** with [faster-whisper](https://github.com/SYSTRAN/faster-whisper)
(no key, no cloud). The browser mic is captured by `streamlit-mic-recorder`, and the coach can
read questions aloud via free `edge-tts`. Defaults to **CPU** (portable); set `CC_WHISPER_DEVICE=cuda`
for GPU, with automatic CPU fallback. Voice packages missing? The app silently falls back to text-only.

Install voice dependencies with:
```bash
pip install -r requirements-voice.txt
```

## 🌐 Deploying your own instance

1. Fork/push this repo to GitHub.
2. Create an app on **[share.streamlit.io](https://share.streamlit.io)** pointing at `app.py`.
3. No secrets required — users paste their own API key in the sidebar when they visit.
4. If you want to pre-configure a default hosted model (so the app works without a key), add
   to **Settings → Secrets**:
   ```toml
   CC_PROVIDER = "hosted"
   CC_HOSTED_BASE_URL = "https://api.groq.com/openai/v1"
   CC_HOSTED_API_KEY = "gsk_your_key_here"
   CC_HOSTED_CHAT_MODEL = "llama-3.3-70b-versatile"
   ```
   See [`.streamlit/secrets.toml.example`](.streamlit/secrets.toml.example) for all options.

## ⚙️ Environment variables (advanced)

All sidebar settings can also be pre-set via `CC_*` env vars or Streamlit secrets. The sidebar
always takes precedence during a live session.

| Var | Default | Purpose |
|-----|---------|---------|
| `CC_PROVIDER` | `ollama` | `ollama` (local) or `hosted` (API) |
| `CC_CHAT_MODEL` | `qwen3:14b-q4_K_M` | Ollama chat model |
| `CC_EMBED_MODEL` | `nomic-embed-text` | Ollama embedding model |
| `CC_OLLAMA_HOST` | `http://localhost:11434` | Ollama endpoint |
| `CC_HOSTED_BASE_URL` | Groq URL | OpenAI-compatible endpoint |
| `CC_HOSTED_API_KEY` | _(empty)_ | Groq / OpenRouter / any compatible key |
| `CC_HOSTED_CHAT_MODEL` | `llama-3.3-70b-versatile` | Model for hosted mode |
| `CC_WHISPER_MODEL` | `base` | Whisper size (`tiny` … `large-v3`) |
| `CC_WHISPER_DEVICE` | `cpu` | `cuda` for GPU (auto-falls back to CPU) |
| `CC_ENABLE_VOICE` | `1` | `0` to disable voice features entirely |

## 🧪 Tests

The suite mocks the LLM — **no Ollama or API key needed** to run it:

```bash
pip install -r requirements.txt
pytest                               # whole suite (13 tests)
pytest tests/test_scoring.py         # deterministic scorer only
pytest tests/test_agents.py::test_writer_returns_kit
```

Covers deterministic scoring, parsers, each agent's JSON contract, and the dossier builder.
