# Skill: Resume Bullet Tailoring (XYZ + STAR)

Rewrite weak, duty-based bullets into quantified, achievement-based bullets tailored to the
target JD — while keeping them **true** to the candidate's real experience.

## The XYZ formula (Google)
> "Accomplished **[X]** as measured by **[Y]** by doing **[Z]**."
Every strong bullet has an **action verb**, a **measurable result**, and **how** it was done.

- Weak:  "Responsible for the data pipeline."
- Strong: "Cut ETL runtime 40% by re-architecting a Spark pipeline serving 12M daily events."

## Principles
- **Lead with impact**, then method. Start with a strong past-tense verb (Built, Led, Reduced,
  Shipped, Automated, Designed).
- **Quantify** wherever the candidate can (%, $, time saved, scale, users). If no metric exists,
  use scope/outcome — never fabricate numbers.
- **Tailor to the JD:** surface the experiences and keywords this specific role cares about; push
  irrelevant detail down or out.
- **One idea per bullet.** Tight, scannable, ~1–2 lines.
- **Honesty rule:** improve phrasing and surface real impact; do NOT invent metrics, tools, or
  responsibilities. If a metric is needed, mark it as a placeholder for the candidate to fill.

## Output
For each improved bullet, return the original, the improved version, which JD keywords it now
carries, and a one-line rationale.
